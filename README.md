# 🛡️ ServerGuard

<div align="center">

### **Manage. Protect. Automate.**

</div>

**ServerGuard** is a desktop application designed to simplify the management and protection of Linux servers through SSH.

Instead of constantly switching between terminals, configuration files and different server utilities, ServerGuard aims to bring essential server-management functionality into one application.

### ⚡ What I'm building

- 🔐 SSH-based server management
- 🛡️ Server security tools
- 🚨 Brute-force protection
- 🔑 SSH key monitoring
- ⚙️ Server hardening
- 📊 Server monitoring
- 🤖 Telegram notifications
- 📁 Server-side automation
- 🔄 Application updates
- 🖥️ Windows desktop interface

### 🧩 ServerGuard architecture

```text

                └─────────────────────────────┘
```
